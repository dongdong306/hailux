
Load a specialized skill when the task matches one of the skills listed in the system prompt. Use this tool to inject the skill's instructions and resources into the current conversation.

The output returns the skill's full instruction body in `<skill_content>`, followed by a `<skill_context>` block with the absolute path of its directory (base directory) and a tree of the other files in that directory (at most 15 files).
Relative paths referenced in the skill are relative to this base directory; use the `read` or `glob` tool to load them.
