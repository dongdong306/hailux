Performs an exact string replacement in a file.
Usage:
- Before editing, you must have used the `read` tool at least once in the conversation. If you attempt to edit a file without reading it first, this tool will report an error.
- When editing text based on the output of the read tool, make sure you preserve the original indentation (tabs/spaces) after removing the line number prefix (format: `<line_number>: `). Do not include any part of the line number prefix in `old_string` or `new_string`.
- In the codebase, **always prefer** editing existing files. **Never** create new files unless explicitly necessary.
- If `old_string` is not found or matches multiple locations, the edit fails — provide a larger string with more surrounding context to make it unique, or use `replace_all` to change every occurrence (useful for renaming a variable across the file).
