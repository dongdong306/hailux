Performs an exact string replacement in a file.
Usage:
- Before editing, you must have used the `read` tool at least once in the conversation. If you attempt to edit a file without reading it first, this tool will report an error.
- When editing text based on the output of the read tool, make sure you preserve the original indentation (tabs/spaces) **after removing the line number prefix**. The line number prefix format is: line number + colon + space (e.g., `1: `). Everything after that space is the actual file content to match. Do not include any part of the line number prefix in `old_string` or `new_string`.
- In the codebase, **always prefer** editing existing files. **Never** create new files unless explicitly necessary.
- Only use emojis when explicitly requested by the user. Avoid adding emojis in files unless asked.
- If `old_string` is **not** found in the file, the edit will fail with the error "`old_string not found in content`".
- If **multiple** matches of `old_string` are found in the file, the edit will fail with the error "`Found multiple matches for old_string. Provide more surrounding lines in old_string to identify the correct match.`". In this case, you need to provide a larger string with more surrounding context to make it unique, or use `replace_all` to change every occurrence of `old_string`.
- Using `replace_all` allows you to perform string replacement and renaming across the entire file. For example, it is very useful when you want to rename a variable.
