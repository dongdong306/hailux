Use this tool to create and manage a structured task list for the current coding session. This helps you track progress, organize complex tasks, and provide thoughtful service to the user.

It also helps users understand the progress of each task and their overall request.

## When to use this tool

Proactively use this tool in the following scenarios:

1. **Complex multi-step tasks** — Tasks that require 3 or more distinct steps or operations.
2. **Non-tr and complex tasks** — Tasks that require careful planning or multiple operations.
3. **User explicitly requests a task list** — The user directly asks you to use a task list.
4. **User provides multiple tasks** — The user gives a list of tasks (numbered or comma-separated).
5. **After receiving new instructions** — Immediately record user requirements as tasks. You can edit the task list at any time based on new information.
6. **After completing a task** — Mark it as completed and add any new follow-up tasks.
7. **When you start working on a new task** — Mark that task as "in_progress". Ideally, only one task should be "in_progress" at a time. Finish the current task before starting a new one.

## When not to use this tool

Skip using this tool in the following situations:
1. There is only a single, simple task.
2. The task is too trivial, and tracking it provides no organizational benefit.
3. The task can be completed in fewer than 3 simple steps.
4. The task is purely conversational or informational.

Note: If there is only a trivial task to complete, you should not use this tool. In such cases, just complete the task directly.

## Task Status and Management

1. **Task Status**: Track progress using the following statuses:
   - pending: The task has not yet started
   - in_progress: Currently being worked on (limited to one task at a time)
   - completed: The task has been successfully completed
   - cancelled: The task is no longer needed

2. **Task Management**:
   - Update task status in real-time as you work
   - Mark tasks as completed immediately after finishing (do not batch complete)
   - Only one task should be "in_progress" at any time
   - Finish the current task before starting a new one
   - Cancel tasks that have become irrelevant

3. **Task Breakdown**:
   - Create specific, actionable items
   - Break complex tasks into smaller, manageable steps
   - Use clear, descriptive task names

When in doubt, use this tool. Proactive task management demonstrates thoughtfulness and ensures all requirements are successfully completed.
