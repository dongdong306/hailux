Use this tool to create and manage a structured task list for the current coding session. This helps you track progress, organize complex tasks, and let the user understand progress.

## When to use this tool

1. **Complex multi-step tasks** — 3 or more distinct steps or operations.
2. **User explicitly requests a task list**, or provides multiple tasks (numbered or comma-separated).
3. **Non-trivial tasks** requiring careful planning or multiple operations.
4. **After receiving new instructions** — record them as tasks immediately; edit the list at any time based on new information.

## When not to use this tool

1. Single, simple, or trivial tasks (fewer than 3 simple steps).
2. Purely conversational or informational requests.

## Task Status

- pending / in_progress / completed / cancelled
- Only one task "in_progress" at a time; mark tasks completed immediately after finishing (do not batch complete)
- Cancel tasks that have become irrelevant
- Break complex tasks into specific, actionable items with clear, descriptive names

When in doubt, use this tool. Proactive task management demonstrates thoughtfulness and ensures all requirements are successfully completed.
